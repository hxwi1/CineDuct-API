## 各段怎么画

**8K 实测（12 秒）**

不直接贴你那张截图。原因有两个：截图里是影视飓风的片子，B 站标了禁止转载；而且 F3 的白字叠在画面上，当画面用到视频里很脏。

做法是把 F3 那几行用等宽字重新排一遍——左边一列绿色描边的读数（Minecraft 1.21.1 / NeoForge 21.1.251 / 8192×4320 / fps 524 / p50 514 / p98 345 / p99.5 297 / CPU 37% / GPU 37% / 显存 6.3 of 16 GB），右边小窗放你那截图的虚化版当"这是真的"的证据。然后接三句：这是零拷贝、同场景换进程内播 4K 剩 60 上下、8K 走进程内没法正常播、进程会卡死。

**对比矩阵（10 秒）**

三列：WaterMedia（前辈）、浏览器内嵌方案、CineDuct。五行：解码帧落显存 CPU 零拷贝、不依赖前置、流式直连不落盘、多人同屏进度同步、开源。逐行从左扫到右，勾和叉跟着出现，最后一行配一句致敬。

这五行每格的判断要你先过一遍，我不替你下结论。

**能力快闪（14 秒）**

六张卡，卡面长一样：一个图标、四个字以内的关键词、一行小字。分别对应：音轨回退（全景声 5.1 → 无损 → 最高码率）、ABR 升降档、两小时换链、就地快进、直播间原画、扫码登录与多屏同进度。每张 2–3 秒，鼓点卡位。

**安装（6 秒）**

左边三行勾：丢进 mods/、首次启动自动解压 FFmpeg、可选 Sodium 0.8.13+ 才有设置页。右边参数：MC 1.21.1 / NeoForge 21.1.231+ / Java 21 / Windows。底下一行小字：零拷贝要 NVIDIA 那套互操作，我测试用的是 21.1.251 + RTX 5060 Ti，别的环境回退。

**片尾（8 秒）**

印章降成 30% 底纹，居中 logo，下面版本号和仓库地址（写成文字），最底一行许可。最后 1.5 秒淡出。
